## RackNerd 架站步骤：两条路线分开走

共享主机路线全程图形界面，VPS 路线需要一点 Linux 基础，两边操作完全不同。

### 路线一：共享主机，从下单到上线四步

1. 下单时选好机房位置和计费周期
2. 把域名解析到主机（改 NS 或加 A 记录），等生效
3. 进 cPanel，用 Softaculous 一键安装 WordPress；不想装程序的话，自带的 SiteJet AI 建站器可以直接拖拽做页面
4. 配置免费 SSL 证书启用 HTTPS，LiteSpeed 缓存默认可用

网站原来放在别的 cPanel 主机上，RackNerd 提供免费搬家。整个过程适合第一次架站的人。

### 路线二：KVM VPS，root 权限自己搭

1. 年付特价下单，选机房
2. 在 SolusVM/KVM 面板装系统（Debian、Ubuntu 之类），随时可重装；需要 IPv6 可以申请加配
3. 搭建环境：用官方 ctrl 面板的一键应用直接部署 WordPress 等自托管程序，或者自己装宝塔、aaPanel 面板再配 LNMP
4. 添加站点、解析域名、签发 Let's Encrypt 证书

选这条路就意味着出问题自己查日志、自己优化，买之前想清楚。
